# Frameworks

Frameworks are built on top of [Core](/core/): higher-level component sets,
theming, and app structure. They are siblings, not a stack - you pick one
(or none) and can always drop down to Core underneath.

## Components

*Maturity: evolving.*

The official component framework: `@solidrt/components`. Buttons, sliders,
navigation shells, theming, and design-system policies, growing toward
Flutter-scale breadth. Its APIs still change; build with it, but expect to
move with it.
