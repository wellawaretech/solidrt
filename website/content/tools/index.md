# Tools

Developer tooling for SolidRT. Today that is `srt`, the command-line tool:

- `srt init` - scaffold a new project from a template.
- `srt` - run your app against the dev server with live reload, on desktop
  or a connected device.
- `srt bundle` / `srt pack` - build for production.
- `srt mcp` - expose the running app to AI agents over MCP: logs, stats,
  render tree, GPU resources, and app-registered debug commands.

A GUI is planned alongside the CLI.
